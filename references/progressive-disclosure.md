# 渐进式披露计划

根级技能应负责路由。子技能应负责决策。参考文档应承载密集表格和易变事实。

| 内容 | 位置 | 加载条件 |
|---|---|---|
| 路由、高级规则 | `SKILL.md` | 始终加载 |
| 提示词构建 | `skills/seedance-prompt/SKILL.md` | 提示词编写任务 |
| 平台/API 事实 | `references/api-status.md` | 平台或 API 任务 |
| 词汇表 | Language skills + references | 翻译/压缩任务 |
| 安全与知识产权 | `seedance-copyright` + `platform-constraints` | 受保护身份或安全敏感任务 |
| 长示例 | `seedance-examples-zh` 或未来的 `examples/` | 用户请求示例时 |

请勿将大型数据库移回活动子技能主体中。

# Seedance 研究快照

last_verified: 2026-05-30

本快照记录了用于 v5.4.4-v5.4.5 版本深度、多语言、视觉素材、专业电影制作、视觉压力测试及表面刷新流程的证据。这是一个带日期的工作层文档，并非对平台访问权限、定价、限制或区域可用性的永久保证。

## 已确认的官方信号

- 字节跳动 Seed 将 Seedance 2.0 描述为统一的多模态音视频生成模型，支持文本、图像、音频和视频输入。
- 官方发布帖指出，用户最多可提供 9 张图片、3 段视频片段、3 段音频片段，以及自然语言指令。
- 官方材料强调构图、镜头语言、运动节奏、视觉效果和声音特征的参考依据。
- 官方材料将视频扩展与编辑描述为核心能力，而不仅是全新的文本生成视频功能。
- 火山引擎的 Seedance 2.0 教程于 2026-05-29 更新，列出了 `doubao-seedance-2-0-260128` 和 `doubao-seedance-2-0-fast-260128`。
- 火山引擎 5 月 29 日的视频生成教程现在是重新核查首帧与末帧角色、返回末帧、网络搜索工具及输入组合规则的活跃第一方渠道。
- 火山引擎的 Seedance 2.0 提示词指南于 2026-05-15 更新，强化了基于角色绑定的多模态参考提示方法。
- 火山引擎 5 月 28 日的定价页面仅在标注来源日期、表面、模型、货币及重新核查免责声明的前提下方可引用。BytePlus 的 JavaScript 渲染页面在引用价格前仍需实时验证。
- Runway 文档记录了一个独立的官方 Seedance 2 表面，使用模型 ID `seedance2`，时长 5-15 秒，托管 `runway://` 上传，以及音频参考组合规则。
- Runway MCP 于 2026-05-27 作为智能体连接器表面推出。请将其视为 Runway 访问/工作流程证据，而非字节跳动 API 能力声明。
- 真人肖像或语音工作流程需要授权、表面支持及平台特定的验证。
- 字节跳动自身的发布材料列出了剩余弱点：细节稳定性、超写实感、动态活力、多主体一致性、文本渲染、复杂编辑，以及偶发的音频失真。
- OpenAI 当前的 Codex Agent Skills 文档将技能描述为包含必需 `SKILL.md` 文件及可选 `scripts/`、`references/`、`assets/` 和 `agents/` 文件夹的目录结构。本仓库遵循该结构。
- 近期的音视频基准测试工作（如 AVBench 和 VABench）强化了跨模态一致性、同步性、唇语 - 语音一致性及音视频问答的评估词汇，但不应将其视为 Seedance 访问权限或性能保证。
- 专业工作流程参考强调，AI 视频提示应将创意镜头意图与交付义务分离：镜头合约、连续性记录、ACES/色彩交接、字幕/本地化规划、音频分轨/M&E/响度、宽高比变体及质检均为工作流程元数据，除非活跃平台明确实现这些功能。

## 实地观察信号

请将这些内容视为从业者指导，而非平台保证：

- 在提交 10-15 秒渲染之前，先制作短草稿片段很有用。
- 每个镜头保持一个主要镜头运动仍是可靠的稳定性规则。
- 参考素材需要明确角色：身份、背景、运动、镜头节奏、音频节拍或末帧目标。
- 首帧/末帧工作流程在中国创作者指南及合作伙伴工作流程文档中较为常见。
- 音频参考失败通常源于角色冲突：如果视频参考也包含声音，当 `[Audio1]` 应控制时序时，请将其静音或将其角色降级为镜头/运动。
- 日语、韩语、西班牙语、俄语及多语言本地化指南强化了相同的核心结构：明确的参考角色、单一镜头运动、清晰动作、声音提示及约束条件。
- 中英混合提示词可用于安全角色绑定及技术镜头术语，但仅作为清晰度辅助。它们并非官方过滤行为，不得用于隐藏不安全意图。
- 当活跃表面支持时，扩展链受益于返回的末帧锚点。
- 编辑或扩展失败片段通常比重新生成整个片段更经济且更可控。
- 产品标志、人脸、可读文本、手部、快速手势及多角色调度受益于锁定构图和更强约束。
- 当 README 以人类可读级别解释工作流程，同时脚本强制执行文件、来源及元数据完整性时，智能体技能仓库更具可用性。
- 专业用户需要角色特定的交付物：导演需要镜头目的与表演节奏，摄影指导需要镜头合约，制片人需要版权/审批节点，剪辑师需要连续性交接，调色师与声音团队需要后期元数据，本地化团队需要无字幕/字幕/配音计划，质检团队需要交付预检。

## 排除在活跃指导之外

- 绕过过滤或规避审核的建议。
- 名人、公众人物或私人模仿。
- 精确复制受保护的角色、系列、工作室、歌曲或声音。
- 来自封装网站的定价承诺，除非回答明确标注封装方、日期及来源。
- 无法重新核查的私密群组、封闭渠道或截图中的声明。
- 用作当前官方平台行为替代品的基准排行榜或论文声明。

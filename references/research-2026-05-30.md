# Seedance 研究快照

last_verified: 2026-05-30

本快照记录了用于 v5.4.4-v5.4.5 版本中镜头深度、多语言、视觉素材、专业电影制作、视觉压力测试和界面刷新验证的证据。这是一个带日期的工作层，并非对平台访问、定价、限制或区域可用性的永久保证。

## 来源优先级

1. 字节跳动 Seed 官方页面和发布文章。
2. 火山引擎或 BytePlus ModelArk 官方文档。
3. 官方或合作伙伴工作流文档，例如 ComfyUI 合作伙伴节点。
4. 提供商发布的学术/模型卡资料。
5. 专业电影、后期制作、调色、字幕、音频和交付标准。
6. 仓库结构的智能体技能打包文档。
7. 社区提示词指南、论坛、提示词语料库和包装器文档。

## 已确认的官方信号

- 字节跳动 Seed 将 Seedance 2.0 描述为一个统一的多模态音视频生成模型，支持文本、图像、音频和视频输入。
- 官方发布文章称用户可提供最多 9 张图片、3 个视频片段、3 个音频片段以及自然语言指令。
- 官方资料强调对构图、镜头语言、运动节奏、视觉效果和声音特征的参考。
- 官方资料将视频扩展和编辑描述为核心能力，而不仅仅是全新的文生视频生成。
- 火山引擎的 Seedance 2.0 教程于 2026-05-29 被观察到更新，并列出了 `doubao-seedance-2-0-260128` 和 `doubao-seedance-2-0-fast-260128`。
- 火山引擎 5 月 29 日的视频生成教程现在是重新核查首帧和尾帧角色、返回尾帧、网页搜索工具和输入组合规则的有效第一方场所。
- 火山引擎的 Seedance 2.0 提示词指南于 2026-05-15 被观察到更新，强化了角色绑定的多模态参考提示。
- 火山引擎 5 月 28 日的定价页面仅可在注明来源日期、界面、模型、货币和重新核查警告的情况下引用。BytePlus JavaScript 渲染页面在报价前仍需实时验证。
- Runway 记录了一个独立的官方 Seedance 2 界面，使用模型 ID `seedance2`，时长 5-15 秒，托管 `runway://` 上传，并包含音频参考组合规则。
- Runway MCP 于 2026-05-27 作为智能体连接界面上线。将其视为 Runway 访问/工作流证据，而非字节跳动 API 能力声明。
- 真人肖像或语音工作流需要授权、界面支持和特定平台验证。
- 字节跳动自身的发布材料列出了剩余弱点：细节稳定性、超写实感、动态活力、多主体一致性、文字渲染、复杂编辑以及偶尔的音频失真。
- OpenAI 当前的 Codex Agent Skills 文档将技能描述为一个目录，包含必需的 `SKILL.md` 以及可选的 `scripts/`、`references/`、`assets/` 和 `agents/` 文件夹。本仓库遵循该结构。
- 近期的音视频基准工作（如 AVBench 和 VABench）强化了围绕跨模态一致性、同步性、唇音一致性和音视频 QA 的评估词汇，但不应将其视为 Seedance 的访问或性能保证。
- 专业工作流参考强调，AI 视频提示词应将创意镜头意图与交付责任分离：镜头合约、连续性台账、ACES/色彩交接、字幕/本地化规划、音频主干/M&E/响度、宽高比变体和 QC 属于工作流元数据，除非活跃平台明确实现了它们。

## 现场观察信号

请将这些作为实践者指导，而非平台保证：

- 在投入 10-15 秒渲染之前，使用短草稿片段是有用的。
- 每个镜头一个主镜头运动仍然是可靠的稳定性规则。
- 参考素材需要明确的角色：身份、背景、运动、镜头节奏、音频速度或尾帧目标。
- 首帧/尾帧工作流在中国创作者指导和合作伙伴工作流文档中很常见。
- 音频参考失败通常是角色冲突：如果视频参考也包含声音，当 `[Audio1]` 应控制节奏时，将其静音或将其角色降级为相机/运动。
- 本地化的日语、韩语、西班牙语、俄语和多语言指南都强化了相同的核心结构：明确的参考角色、一个镜头运动、清晰的动作、声音提示和约束。
- 中英文混合提示词对于安全角色绑定加专业镜头术语可能有用，但仅作为清晰性手段。它们不是官方过滤行为，且不得用于隐藏不安全意图。
- 当活跃界面支持时，扩展链受益于返回的尾帧锚点。
- 编辑或扩展失败的片段可能比重新生成整个片段更便宜且更可控。
- 产品标识、人脸、可读文本、手部、快速手势和多角色遮挡受益于锁定构图和更强的约束。
- 当 README 以人类可读层面解释工作流，同时脚本强制执行文件、来源和元数据完整性时，智能体技能仓库更易于使用。
- 专业用户需要角色特定的工件：导演需要镜头意图和表演节拍，摄影指导需要镜头合约，制片人需要权利/审批关卡，剪辑师需要连续性交接，调色师和声音团队需要后期元数据，本地化团队需要无字/字幕/配音计划，QC 团队需要交付预检。

## 排除在活跃指导之外

- 绕过过滤或规避审核的建议。
- 模仿名人、公众人物或私人个体。
- 精确复制受保护角色、特许经营权、工作室、歌曲或声音。
- 来自包装器网站的定价承诺，除非回答明确标注了包装器、日期和来源。
- 来自私人群组、封闭渠道或无法重新核查的截图的声明。
- 用作当前官方平台行为替代品的基准排行榜或论文声明。

## 更新规则

每当 README、平台状态文档、API 指南或模型名称映射发生变化时，刷新本快照。如果某项声明未关联来源和日期，则将其移至现场观察注释或将其移除。
